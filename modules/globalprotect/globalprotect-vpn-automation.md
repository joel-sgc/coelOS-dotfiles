# GlobalProtect VPN (LUC): wrapper contract

Scriptable connect/disconnect for LUC's GlobalProtect portal (`secureaccess.luc.edu`),
built to be driven by a program (the Quickshell VPN modal, a TUI). Backend is
openconnect (`modules/globalprotect-openconnect.nix`, `modules/globalprotect-routes.nix`,
`home/globalprotect.nix`, `home/globalprotect/*`); read the header comments there for
the privilege split and why the HIP report is generated by `openconnect-hipreport.sh`.
The earlier vendored PanGPS/PanGPA client is gone; don't go looking for it.

## Auth model

Plain portal username + password, then a gateway MFA code (Microsoft verification
code). Not SAML, despite `saml-default-browser=yes` in the prelogin response. The portal
never lets the client save the password. The password lives in the login keyring
(`secret-tool`, service `coel-vpn`); an optional TOTP seed (`coel-vpn-set-mfa-secret`)
lets `coel-vpn-connect` generate the code itself. Without the seed a human supplies it.

## Commands (all on PATH)

| Command | Purpose |
|---|---|
| `coel-vpn-set-password` / `coel-vpn-forget-password` | Store / remove the portal password in the keyring |
| `coel-vpn-set-mfa-secret` | Optional TOTP seed so connects need no human |
| `coel-vpn-connect [MFA_CODE]` | Connect; `GP_STATUS:` lines on stdout, raw client output on stderr |
| `coel-vpn-disconnect` | Disconnect, prints `GP_STATUS: disconnected` |
| `coel-vpn-status` | One token: `connected` / `disconnected` / `unknown`; exit 0 iff connected |

`GP_PASSWORD` in the environment bypasses the keyring (headless, no session bus).

## `coel-vpn-connect` contract

MFA code precedence: argument, then `GP_MFA_CODE`, then stored TOTP seed, then one line
on stdin after `GP_STATUS: mfa-required` is printed. No pty needed by the caller.

Statuses are authoritative in the `echo "GP_STATUS: ..."` lines of `home/globalprotect.nix`
and `home/globalprotect/openconnect-authenticate.exp`; the ones consumers rely on:
`connecting`, `mfa-required`, `mfa-rejected` (another `mfa-required` follows),
`connected`, `auth-failed`, `no-password`, `timeout`, `unexpected-exit`, `disconnected`.

Never hot-loop connect on failure: repeated bad portal auth can lock the account.

## Gotchas worth knowing

- **Route hijack**: a full-tunnel connect injects a route for the whole local subnet
  through the tunnel, breaking local DNS/LAN. `modules/globalprotect-routes.nix` /
  `home/globalprotect/vpn-routes.sh` fix it with policy routing; if LAN/DNS breaks
  while connected, look there first.
- **HIP**: the gateway only grants the base network tier if the HIP report shows a
  firewall; antivirus is not needed for base-tier access.
- Connecting to LUC (full tunnel) breaks Claude Code's own connectivity. Don't test
  connect from inside a session you need.
